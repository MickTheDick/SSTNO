SSTNO developer baseline. You are not starting a shift on a space station.

The default round is a small outdoor test area for a human character. It exists so this fork can boot and be played without a station, an emergency shuttle, or an antagonist. It is not the regional map and it is not a finished settlement.

Hunger, thirst, injury, building, and combat still apply. Ask an admin for help with the escape key, then admin help.
